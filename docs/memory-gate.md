# 模型语义长期记忆门控

采用 LlamaIndex LLMSingleSelector 的来源路由思路：给模型说明两条路线及其适用范围，由模型结合问题和上下文选择路线。本项目使用现有 LLMClient 和 Pydantic 独立实现，没有安装或调用 LlamaIndex，也没有训练新的分类器。

参考开源实现：
- https://github.com/run-llama/llama_index/blob/main/llama-index-core/llama_index/core/selectors/llm_selectors.py
- https://github.com/AkariAsai/self-rag

Self-RAG 的专用反思 token 和训练流程无法直接套用到现有 GLM API，因此本次选择无需训练的模型路由。MemPalace 保留为历史存储与检索层。

## 调用流程

当前问题 → 当前视频证据检索 → 模型门控 → 可选的 historical_context → 回答生成与来源校验 → 可选的证据补全与重答。

门控输入：当前问题、视频标题、已解析意图、最近最多 6 条对话、最多 5 条当前视频证据摘要。每条历史问答分别最多 600 字符，证据文本最多 400 字符。门控不会为了做决定预先查询 MemPalace。

输出示例：

```json
{"route":"search_history","reason":"用户要求与其他视频比较","query":"训练方法的适用条件与局限"}
```

- `current_video_only`：不调用历史检索。当前视频内部比较、总结、时间定位不因出现某个关键词自动触发历史搜索。
- `search_history`：用模型生成的独立查询检索 MemPalace，仍经过原有相似度、来源核验、去重和上下文预算控制。决定检索不代表一定能找到可用历史。
- 每次公开 `answer()` 调用重置判断；同一次提问的补帧重答复用门控决定。历史检索结果不缓存，仍会重新检索和校验。
- 无当前视频分段或当前证据不足而提前返回的路径保持原行为，本次没有把应用改为无条件跨库问答入口。

## 配置与失败处理

```dotenv
MEMORY_GATE_MODE=auto
MEMORY_GATE_MODEL=
MEMORY_GATE_TIMEOUT_SECONDS=20
```

`auto` 默认让模型判断；`always` 保留每次查询历史的行为；`off` 关闭历史查询。MemPalace provider 为 `noop` 时直接关闭，不调用门控模型。模型为空时使用主问答模型，也可指定同一模型接口支持的其他模型名；是否更省钱、更快需要实测。

门控最多请求 512 个输出 token，禁用 thinking，不进行 API 重试或 JSON 修复。20 秒是 HTTP 超时参数，不是包含限流排队在内的整轮问答时长上限。门控和主问答共享并发限流器。

超时、接口错误或非法 JSON 时返回 `current_video_only`，记录 `source=fallback` 和错误类型，继续当前视频回答。这个策略会漏掉部分本该使用历史的问题，不能称为百分之百准确。日志中的 `memory_gate` 事件包含路线、理由、查询、来源与本轮是否复用；持久化问答时写入原有证据 trace。

门控是提示词驱动的语义判断，配置开关和输出校验仍是确定性代码。历史材料作为数据传入，提示模型不执行其中的指令；这一提示本身不构成对提示注入的绝对保证。

## 验证与代价

`tests/test_memory_gate.py` 检查结构化选择、输入窗口、配置开关、非法输出与超时降级、检索是否真的跳过、重答复用及新问题重置、共享限流和禁止重试。

真实模型检查：运行 `python -m app.evals.memory_gate_smoke`，会使用已配置的模型 API 并产生用量，但不查询或写入 MemPalace。报告写入 `data/eval/memory_gate_smoke.json`。

2026-09-06 对当前配置的 GLM-5.1 测试 6 条合成问题，6 条路由符合预期：同视频总结、同视频比较、显式跨视频比较、带时间点的跨视频比较、禁止历史、依赖最近对话的跨视频指代。单条约 4.10–6.74 秒，平均 5.32 秒；这些样本没有传入实际视频证据，不代表真实业务准确率或生产延迟。

每次符合条件的问答增加一次模型调用。省下的是不必要的历史检索和历史上下文，并不保证总时延或总成本下降；当前默认复用 GLM-5.1 时，额外数秒需要作为明确代价。后续应收集真实问题标注集，评估漏检率、误检率、成本与 P95 时延，再决定是否使用更轻量模型或蒸馏分类器。
